## Rules

1. Read the target number.
2. Select exactly two tiles.
3. Their values must add to the target.
4. Start a new target for another round.

## A brief history

Target-number puzzles have long been used in classrooms and puzzle books to make mental arithmetic playful. The well-known Countdown numbers game uses the same search-for-a-sum idea.

## Privacy

Tiles and targets are generated in the browser. Nothing is saved remotely.
