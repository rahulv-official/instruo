## Rules

1. Focus the text area and start typing.
2. The thirty-second timer starts on focus or first input.
3. Keep typing until time reaches zero.
4. This lightweight version reports words typed, not a ranking.

## A brief history

Typing tests became common with typewriters and office training courses. Modern versions help people practice keyboard familiarity without needing a sign-up or a leaderboard.

## Privacy

Typed text and timer state live only in this browser tab.
