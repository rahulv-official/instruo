## Usage

Paste an OpenAPI 3 or Swagger 2 document to inspect servers, tags, security schemes, every operation, parameters, request bodies, responses, reusable components, and the raw parsed document. JSON and YAML are supported.

## Privacy

Specifications are parsed locally and never uploaded.
