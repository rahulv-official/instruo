## Translate Morse code

Convert letters and numbers to International Morse code or decode Morse symbols back to text. Separate letters with spaces and words with `/`.

## Supported characters

This converter supports letters A to Z, digits 0 to 9, spaces, dots, and dashes. Unsupported punctuation is ignored while encoding.
